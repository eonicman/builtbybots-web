● Recording… 0.0s

Presets are classic keyboard/tracker-style sounds, synthesized instantly — no file needed. Same instruments the two official tracks (Canon in D, Für Elise) and Boot Sequence are built from. Recording asks for mic access, caps at 15s, and auto-trims leading/trailing silence — sing or play something and it becomes an instrument like any other.

Pattern

Click a cell to select it (arrow keys also move the selection), then use the controls above to set or clear it.

Merging copies every note from one channel into the other (wherever the destination row is empty), then clears the source channel out — a quick way to free up a channel for a new part once all 4 are in use. If both channels have notes on the same row, the merge is blocked and tells you which rows conflict. Undo Merge reverses only the most recent merge, restoring both channels exactly as they were — handy if you need to pull a part back out onto its own channel to adjust it.

A track-level effect, not per-cell: pick a channel and an effect and it's stamped onto every note already in that channel, plus any note you add to it afterward, until you change it again. Intensity 0 means no audible effect even with a type selected. Cells carrying an active effect show a letter after the note (F/D/X/V).

Your Published Mods

Publish a .xm Track

Already have a track made in a real tracker (MilkyTracker, OpenMPT, etc.)? Publish the raw .xm file straight to the floating player — it plays back via libopenmpt, the same engine real tracker software uses, so effects/instruments/channels beyond this editor's own 5×128 grid all come through correctly. This is a separate path from the grid above — an .xm file isn't loaded into the editor, just published as-is.
