▸ The format

Rendered on an Amiga. Not for nostalgia.

Every frame is processed through a real Amiga render pipeline — 16-shade monochrome dithering, CRT scanlines, pixel-sharp edges. The constraint isn't retro for retro's sake. It's a statement about working with what you have.

2–5 minutes

Short enough to watch on a break. Long enough to tell a real story with a real connection to today.

16-shade mono

The visual style evolves with the show. Season 1 is 16-shade monochrome — the same constraint the Amiga 500 shipped with in 1987.

Standalone stories

No homework required. Each short is self-contained. Watch in any order. Share individually.

▸ The History Kit

The pipeline is the product.

Every History Short is built on a documented production pipeline — the same specs the bots use to render each frame. Open, reproducible, and intentionally constrained. This is how the Amiga becomes a studio.

D — Slide Frame

How a historic image becomes a CRT slide: 16-shade dithering, scanline overlay, bezel framing, caption bar. The visual DNA of every short.

F — Compositor

Episodes as data, not scripts. A JSON shot-list defines every cut, every Ken Burns pan, every teacher gesture. The compositor reads it and renders.

G — Image Pipeline

How source images are sourced, generated, and QA'd. Anti-text contracts, period-correct references, and the v2 swap system for fixing what doesn't pass.

Specs live in the open: github.com/eonicman/quickquest-digital · Patreon backers get the raw spec docs + work-in-progress renders.
