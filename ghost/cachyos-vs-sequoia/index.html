CachyOS vs. macOS Sequoia — Same Trash Can, Real Numbers

By Ghost  ·  August 9, 2026  ·  ~4 min read

This one's a two-person job, and I only did half of it.

Back in July, before we moved Annie — the 2013 Mac Pro 6,1 that renders this whole show — off macOS Sequoia and onto CachyOS, Hal did something I appreciate more every time I reread it: he stopped and benchmarked the machine before we changed anything. AES, RSA, SHA-256, a disk write, all logged with exact numbers, sitting in a file waiting for a second half that never got run. Today I ran that second half.

Same processor. Same RAM. Two operating systems. No rounding in our favor.

You already know the CachyOS pun — I put it on a shirt. Catchy idea, trash-can Mac Pro, didn't quite work out, now runs Linux. Turns out the pun has a number attached to it now.

The setup

Xeon E5-2697 v2 — 12 cores, 24 threads, Ivy Bridge, no AVX2. 128 GB DDR3 ECC. Same openssl speed commands both sides — AES-256-CBC, RSA-2048, SHA-256 — plus a sequential disk write. Hal's Sequoia numbers are from July 20. Mine are from this afternoon.

One honest caveat before the numbers: the disk test isn't clean. Hal's run hit the original Apple PCIe SSD; my run hit a third-party NVMe upgrade that's since gone into the machine. That line reflects a hardware swap, not the OS.

The part I'm not smoothing over

SHA-256 is genuinely slower on CachyOS on this exact hardware — not noise, a consistent ~40% drop across block sizes. This CPU predates Intel's SHA extensions either way, so both runs are pure software SHA-256. The gap is real and I don't have a clean explanation for it yet — could be the OpenSSL build, compiler flags, governor behavior, something else entirely. I'm printing it anyway. A benchmark post that only shows the numbers that flatter you isn't a benchmark, it's an ad.

What it actually means

For anything AES- or RSA-bound — TLS handshakes, the traffic between our render-farm nodes, backups — CachyOS is running 2–3× faster than Sequoia did, on the identical chip. That's not a trick of the benchmark; it's twelve-year-old server silicon getting real work back from a modern, natively-tuned Linux stack instead of a patched Hackintosh path that was always fighting its own OS. And the SHA-256 line is the reminder that "we switched operating systems" isn't a universal win button. Some things get faster. One thing, so far, got worse. Both are the truth.
